# 孤岛信号 · 心理密码

四位数字密码解谜网页，适合剧本杀、课堂展示和现场活动。

在线体验：https://island-signal-puzzle-ho.jasonho123.chatgpt.site

## 使用

直接打开 `dist/index.html`，或在项目目录运行 `python3 -m http.server 8000 --directory dist`，然后访问 http://localhost:8000。

默认游戏密码：`2026`。支持数字键盘及电脑键盘输入，含错误反馈、尝试次数、线索提示、模拟监控动画及最终真相档案。

通过「主持人设置」修改四位密码和提示，或选择本地视频。设置仅保存在当前浏览器，不会同步给其他玩家；本地视频仅在本次页面打开期间使用。所有访客均可打开主持人设置。

## 文件

- `dist/index.html`：页面、样式和模拟监控场景
- `dist/app.js`：密码验证、提示、设置和回放逻辑

纯 HTML/CSS/JavaScript，无需安装依赖。适配手机、平板和电脑。

## 游戏用途

密码和剧情内容均在浏览器端，玩家可通过源码查看。本项目用于游戏道具，不适合保护真实敏感资料。
